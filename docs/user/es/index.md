# Guía de usuario de Swage

*[English](../en/index.md)*

Swage es un editor de tipografías paramétrico. Una fuente es un conjunto de
medidas (parámetros) y de recetas que construyen cada letra a partir de ellas.
Ajustas las medidas, miras palabras enteras y sacas cualquier glifo del sistema
para dibujarlo a mano cuando una receta no basta.

## Por dónde empezar

1. [Primeros pasos](getting-started.md): crear una fuente, conocer la ventana,
   exportarla.
2. [Conceptos](concepts.md): parámetros, recetas, piezas, componentes, áreas y
   disposiciones. Léelo una vez; el resto de la guía lo da por sabido.

## Ayuda dentro de la app

- Pasa el puntero por cualquier botón, parámetro o línea: un tooltip dice qué hace y
  para qué sirve. **Ver → Detalle de la ayuda** elige completa, breve o solo el nombre.
- **F1** abre la página de la guía de lo que hay bajo el puntero.
- **Ctrl+K** busca por nombre cualquier orden, área, disposición, glifo o parámetro.
- **Ayuda → Informar de un problema…** abre un *issue* con la versión y el sistema
  rellenos.
