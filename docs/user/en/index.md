# Swage user guide

*[Español](../es/index.md)*

Swage is a parametric type design editor. A font is a set of measurements
(parameters) plus recipes that build each letter from them. You tune the
measurements, look at whole words, and take any glyph out of the system to draw it
by hand when a recipe is not enough.

## Start here

1. [Getting started](getting-started.md): create a font, look around, export it.
2. [Concepts](concepts.md): parameters, recipes, pieces, components, areas and
   layouts. Read it once; the rest of the guide assumes it.

## Help inside the app

- Hover any button, parameter or line: a tooltip says what it does and why.
  **View → Help detail** chooses full, brief or name only.
- **F1** opens the guide page for what is under the pointer.
- **Ctrl+K** finds any command, area, layout, glyph or parameter by name.
- **Help → Report a problem…** opens an issue with the version and system filled in.
